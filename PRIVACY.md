# Privacy Policy for agent-audit-action

**Last Updated:** October 2026

`agent-audit-action` is an open-source GitHub Action that runs security checks within your GitHub Actions workflow environment.

## 1. Zero External Telemetry
- No telemetry, analytics, repository metadata, or audit outputs are sent to any external servers.
- All checks run strictly within GitHub's ephemeral runner container.

## 2. Artifact Retention
- Any generated SARIF or JSON reports remain within your GitHub repository workflow artifacts under your organization's control.

Contact `mo9652962-ai@users.noreply.github.com` for questions or concerns.
